# Portfolio - Rotating Squares

Simple site of eight multicoloured squares rotating around a golden one, on a black background. for demonstration skills and display on 
[Portfolio Repository](https://github.com/GustavoBrizola/Portfolio)

## Project Goals
* Visual demonstration tecnique practice
* Deep understanding on .CSS and how they interact with animations
* Make avaliable to [Portfolio Repository](https://github.com/GustavoBrizola/Portfolio) can fetch `RotatingSquares/ProjectInfo.json` and use data avaliable and turn direct link
